# MARQ Gen 3 — демонстраційний сайт

Адаптивна преміальна головна сторінка українською мовою. Код без фреймворків: HTML + CSS + JavaScript.

## Як запустити

1. Розпакуйте ZIP-архів.
2. Відкрийте `index.html` у браузері. Інтернет потрібен для фото годинників з офіційного CDN Garmin, вебшрифтів і переходів на джерела. Якщо зображення з CDN не завантажуються, сайт автоматично показує локальні SVG-ілюстрації.
3. Для публікації розмістіть папку на статичному хостингу (Vercel / GitHub Pages / Netlify). Серверна частина не потрібна.

## Що реалізовано

- За референсом: велика hero-секція, темний графіт і синій #1F5F99, радіальні підсвічування, підставка, 6 товарних карток, широкий промобанер та додаткові плитки.
- Сітка: 6 колонок на широкому екрані, 3 на середньому, 2 на вузькому (на дуже вузьких екранах теж 2).
- Робочі модальні вікна: усі шість моделей, нові технології, історія бренду, джерела, застереження, порівняння, пошук і обране.
- Порівняння до 4 вибраних моделей; обране та вибір для порівняння запам'ятовуються через localStorage.
- Доступність: нативний <dialog>, закриття Escape або кліком по тлу, keyboard focus, aria-label, prefers-reduced-motion.

## Контент і фото

Тексти побудовані за офіційними матеріалами Garmin від 13.10.2026. Головні зображення, усі шість товарних карток, зображення у модальних вікнах і пошуку **звертаються напряму до офіційного CDN Garmin** `https://res.garmin.com/`.

URL базується на артикулі конкретної моделі Gen 3 за шаблоном:
`https://res.garmin.com/en/products/АРТИКУЛ/v/cf-lg.jpg`

- Adventurer: 010-04549-00
- Athlete: 010-04549-10
- Aviator: 010-04549-20
- Commander: 010-04549-30
- Diver: 010-04549-40
- Golfer: 010-04549-50

Адреси сформовані за типовою схемою Garmin CDN та підтвердженими артикулами. **Безпосередню HTTP-доступність кожної картинки з цього середовища підтвердити не вдалося.** Тому додано механізм fallback: якщо сервер не видає фото (404, hotlink blocking тощо), автоматично завантажується резервна локальна SVG-ілюстрація з `assets/`. Для роботи з CDN потрібне підключення до інтернету. Політика прямих посилань може змінитися на стороні Garmin.

Зверніть увагу: ціни — USD MSRP США, не локальні ціни. Доступність LTE, inReach і ECG залежить від регіону/тарифу.

## Зміна палітри

У `styles.css` у `:root` змінюйте `--bg`, `--bg2`, `--blue`, `--text`. Основний синій #1F5F99. Зображення та стилі використовують взаємодоповнювальні відтінки.
